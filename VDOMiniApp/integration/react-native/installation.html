React Native Installation

Requirements​

Hạng mụcGiá trị
React Native0.73+
Node20.19.0 (xem .nvmrc của SDK)
CocoaPods>= 1.13
Xcode15+
Minimum iOS13.4
Android minSdk24
Android compileSdk35
Tài khoản JFrogBắt buộc cho cả npm registry và binary iOS

Bước 1: Cấu hình registry npm​

SDK được phát hành trên Artifactory nội bộ. Trỏ scope @vdo về registry đó.

Yarn (Berry / 2+)​

~/.yarnrc.yml:

npmScopes:
  vdo:
    npmRegistryServer: "https://mobile-data.viettelmoney.vn/artifactory/vdo-npm-packages"
    npmAlwaysAuth: true
    npmAuthIdent: "${JFROG_USERNAME}:${JFROG_PASSWORD}"

npmAlwaysAuth: true là bắt buộc. Thiếu nó, Yarn bỏ header xác thực khi tải tarball và nhận 401.

npm / Yarn Classic​

~/.npmrc:

@vdo:registry=https://mobile-data.viettelmoney.vn/artifactory/vdo-npm-packages/
//mobile-data.viettelmoney.vn/artifactory/vdo-npm-packages/:_auth=<base64 của username:password>

Sinh giá trị _auth:

printf '%s:%s' "$JFROG_USERNAME" "$JFROG_PASSWORD" | base64

Bước 2: Cấu hình credential cho binary iOS​

Các pod binary (VDOMiniApp, VDONetwork, VDOUtils, và nhóm eKYC) được tải zip từ Artifactory bằng HTTP Basic. Podspec đọc credential theo thứ tự: biến môi trường JFROG_USERNAME/JFROG_PASSWORD, rồi ios-specs/jfrog_credentials.rb, rồi ~/.netrc.

export JFROG_USERNAME="<username>"
export JFROG_PASSWORD="<password>"

Hoặc khai trong ~/.netrc:

machine mobile-data.viettelmoney.vn
login    <username>
password <password>

File này cũng phục vụ curl và Gradle (Bước 5).

Bước 3: Khai báo dependency​

Version hiện tại: 2.2.2-rc01 (release candidate, dist-tag rc). Xem lịch sử phát hành để biết các bản khác.

Mini App tiêu chuẩn​

{
  "dependencies": {
    "@vdo/vds-rn-sdk": "2.2.2-rc01"
  }
}

Khai bằng đúng tên scoped. Hệ quả với app đang dùng tên cũ vds-rn-sdk:

  • import VdsMiniApp from '@vdo/vds-rn-sdk' — phải sửa câu import
  • đường dẫn podspec trong Podfile thành ../node_modules/@vdo/vds-rn-sdk/ios-specs/...
Nên khai bằng tên scoped

"vds-rn-sdk": "npm:@vdo/vds-rn-sdk@2.2.2-rc01" giữ được câu import cũ nhưng thư mục trong node_modules vẫn là vds-rn-sdk. Autolinking đặt tên Gradle project theo tên thư mục, nên project thành :vds-rn-sdk thay vì :vdo_vds-rn-sdk — mọi dòng implementation project(...) trong app phải đổi theo. Ghim version tuyệt đối, không dùng ^.

Mini App có eKYC​

@vdo/vds-rn-sdk-ekyc phát hành lần đầu ở 2.2.2-rc01 — xem release note.

{
  "dependencies": {
    "@vdo/vds-rn-sdk": "2.2.2-rc01",
    "@vdo/vds-rn-sdk-ekyc": "2.2.2-rc01"
  }
}

Hai package khai cùng một version: peerDependencies của gói eKYC ghim đúng một version, nên ^ sẽ làm hai số lệch nhau ở bản vá tiếp theo.

Gói eKYC không có API JavaScript. Không import gì thêm — khai package là đủ.

Bước 4: Cấu hình iOS​

4.1. Khai báo pod trong Podfile​

Ba pod binary của bản tiêu chuẩn:

target 'YourApp' do
  pod 'VDOMiniApp', :podspec => '../node_modules/@vdo/vds-rn-sdk/ios-specs/VDOMiniApp/VDOMiniApp.podspec'
  pod 'VDONetwork', :podspec => '../node_modules/@vdo/vds-rn-sdk/ios-specs/VDONetwork/VDONetwork.podspec'
  pod 'VDOUtils',   :podspec => '../node_modules/@vdo/vds-rn-sdk/ios-specs/VDOUtils/VDOUtils.podspec'

  config = use_native_modules!
  use_react_native!(:path => config[:reactNativePath], :hermes_enabled => true)
end

Bản có eKYC thêm sáu pod nữa:

  EKYC = '../node_modules/@vdo/vds-rn-sdk-ekyc/ios-specs'
  pod 'VDOEkycService',          :podspec => "#{EKYC}/VDOEkycService/VDOEkycService.podspec"
  pod 'VDOMiniAppEkycConnector', :podspec => "#{EKYC}/VDOMiniAppEkycConnector/VDOMiniAppEkycConnector.podspec"
  pod 'eKYC',                    :podspec => "#{EKYC}/eKYC/eKYC.podspec"
  pod 'NFC',                     :podspec => "#{EKYC}/NFC/NFC.podspec"
  pod 'ncnn',                    :podspec => "#{EKYC}/ncnn/ncnn.podspec"
  pod 'openmp',                  :podspec => "#{EKYC}/openmp/openmp.podspec"

Bản tiêu chuẩn:

cd ios && pod install

4.2. Dynamic framework: bản có eKYC​

eKYC, NFC và VDOEkycService liên kết động tới CryptoSwift. Dựng static thì app crash ngay lúc khởi động (dyld: Library not loaded: @rpath/CryptoSwift.framework). Bản có eKYC phải cài ở chế độ dynamic framework:

cd ios && USE_FRAMEWORKS=dynamic pod install

Podfile mẫu của React Native đọc biến USE_FRAMEWORKS. Nếu Podfile của app đã bỏ đoạn đó, khai thẳng use_frameworks! :linkage => :dynamic trong target.

Ở chế độ dynamic, CocoaPods chặn vì ncnn và openmp là binary static. Thêm pre_install vào Podfile để tắt kiểm tra đó:

pre_install do |installer|
  Pod::Installer::Xcode::TargetValidator.send(
    :define_method, :verify_no_static_framework_transitive_dependencies
  ) {}
end

4.3. Permissions: bản có eKYC​

Info.plist:

<key>NSCameraUsageDescription</key>
<string>Ứng dụng cần camera để chụp giấy tờ và xác thực khuôn mặt</string>
<key>NSMicrophoneUsageDescription</key>
<string>Ứng dụng cần microphone cho luồng xác thực</string>
<key>NSPhotoLibraryUsageDescription</key>
<string>Ứng dụng cần thư viện ảnh để chọn ảnh giấy tờ</string>
<key>NFCReaderUsageDescription</key>
<string>Ứng dụng cần NFC để đọc chip trên giấy tờ tùy thân</string>

4.4. NFC capability​

Bật Near Field Communication Tag Reading trong Signing & Capabilities. App ID trên Apple Developer portal phải có capability này, nếu không profile sẽ không ký được.

Entitlements:

<key>com.apple.developer.nfc.readersession.formats</key>
<array>
  <string>NDEF</string>
  <string>TAG</string>
</array>

Info.plist:

<key>com.apple.developer.nfc.readersession.iso7816.select-identifiers</key>
<array>
  <string>A0000002471001</string>
</array>

NFCReaderUsageDescription đã khai ở mục 4.3, không khai lại.

Cần đủ cả hai. Thiếu entitlement formats, luồng định danh dừng ở bước quét chip và mini app báo thiết bị không hỗ trợ — không có lỗi ký nào hiện ra, nên rất dễ tưởng là lỗi khác.

4.5. HTTP trên môi trường staging​

Môi trường staging dùng HTTP thô trên IP trần, nên cần ngoại lệ ATS. Thay <staging-host> bằng host do team cấp:

<key>NSAppTransportSecurity</key>
<dict>
  <key>NSExceptionDomains</key>
  <dict>
    <key><staging-host></key>
    <dict>
      <key>NSTemporaryExceptionAllowsInsecureHTTPLoads</key><true/>
      <key>NSIncludesSubdomains</key><true/>
    </dict>
  </dict>
</dict>

Bản production dùng HTTPS, không cần khối này.

4.6. Simulator trên Apple Silicon​

Bản có eKYC không build được cho simulator arm64 — podspec đặt EXCLUDED_ARCHS[sdk=iphonesimulator*] = arm64 vì VDOMiniAppEkycConnector.xcframework thiếu slice đó. Dùng máy thật, hoặc chạy Xcode dưới Rosetta.

Bước 5: Cấu hình Android​

5.1. Build config​

android/build.gradle:

buildscript {
  ext {
    minSdkVersion     = 24
    compileSdkVersion = 35
    targetSdkVersion  = 35
  }
}

Bản có eKYC còn cần dataBinding ở module app:

android {
  buildFeatures {
    viewBinding true
    dataBinding true
  }
}

Thiếu dataBinding, build vẫn xanh nhưng màn eKYC crash lúc mở.

Bản có eKYC cũng cần bật Jetifier trong android/gradle.properties, vì AAR eKYC kéo thư viện support cũ trùng lớp với androidx.core:

android.enableJetifier=true

5.2. Repository native​

android/build.gradle:

def localProperties = new Properties()
def localFile = rootProject.file("local.properties")
if (localFile.exists()) {
  localFile.withInputStream { localProperties.load(it) }
}

allprojects {
  repositories {
    maven {
      url = uri("https://mobile-data.viettelmoney.vn/artifactory/gradle-viettelmoney/")
      credentials {
        username = localProperties.getProperty("maven.viettelmoney.username")
            ?: System.getenv("MAVEN_VIETTELMONEY_USERNAME") ?: ""
        password = localProperties.getProperty("maven.viettelmoney.password")
            ?: System.getenv("MAVEN_VIETTELMONEY_PASSWORD") ?: ""
      }
    }
    maven { url "https://jitpack.io" }
  }
}

android/local.properties:

maven.viettelmoney.username=<username>
maven.viettelmoney.password=<password>

5.3. Permissions​

AndroidManifest.xml — bản có eKYC:

<uses-permission android:name="android.permission.CAMERA" />
<uses-permission android:name="android.permission.RECORD_AUDIO" />
<uses-permission android:name="android.permission.NFC" />
<uses-permission android:name="android.permission.READ_MEDIA_IMAGES" />
<uses-feature android:name="android.hardware.camera" android:required="true" />
<uses-feature android:name="android.hardware.nfc" android:required="false" />

5.4. HTTP trên môi trường staging​

Android 9 trở lên chặn cleartext mặc định. Dùng staging qua HTTP thì đặt android:usesCleartextTraffic="true" trong thẻ <application> của manifest dành riêng cho staging/debug. Đừng bật cho bản UAT/production.

Bước 6: Verify​

Code JS chỉ import package nền:

import VdsMiniApp from '@vdo/vds-rn-sdk';

Build hai nền tảng:

yarn install
cd ios && pod install && cd ..
yarn ios
yarn android

Bản có eKYC thay bước pod install bằng USE_FRAMEWORKS=dynamic pod install (mục 4.2).
