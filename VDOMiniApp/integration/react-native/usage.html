React Native Usage

import VdsMiniApp from '@vdo/vds-rn-sdk';

Mở Mini App​

await VdsMiniApp.openMiniApp(
  '01ktay2kqzkmdfk96efg4ybew2',   // miniAppKey do App Center cấp
  initRequest,                     // dữ liệu phiên, xem dưới
  parameter,                       // tuỳ chọn: tham số truyền cho mini app
  themeConfig,                     // tuỳ chọn
);

Sau lời gọi này SDK lấy client_token, gọi API lấy manifest, dựng URL và mở WebView.

Tạo initRequest​

JSON mà SDK chuyển nguyên vẹn xuống mini app:

const initRequest = {
  data: {
    external: {
      generalInfo: {
        msisdn: '84xxxxxxxxx',
        orderId: '<mã giao dịch của host>',
      },
      serviceInfo: {},
    },
    internal: {
      deviceInfo: {
        imei: '<imei>',
        platform: {os: 'Android', osVersion: '14'},   // 'Android' | 'Ios'
      },
      session: {
        auth: {
          accessToken: '<access token của host>',
          refreshToken: '<refresh token>',
          username: '<msisdn>',
          imei: '<imei>',
        },
        accInfo: {
          accountId: '...',
          displayName: '...',
          language: 'vi',
          avatar: 'https://...',
        },
      },
    },
  },
  eventStatus: {errorCode: 'SDK000'},
  request_id: '<id yêu cầu>',
  event: 'INIT',
  sender: 'MINIAPP_SDK',
};

Các trường chính​

TrườngBắt buộcGhi chú
data.internal.sessionCó, nếu mini app cần đăng nhậpnull thì mini app không xác định được khách hàng
data.internal.deviceInfoNên cóimei và platform.os/osVersion
data.external.generalInfoTheo mini appMỗi mini app quy định trường riêng, ví dụ msisdn, orderId
data.external.serviceInfoTheo mini appĐể {} nếu không dùng
eventStatus.errorCodeCóSDK000 nghĩa là host dựng dữ liệu thành công
event, senderCóLuôn là INIT và MINIAPP_SDK

Mini app đọc data.external để lấy tham số nghiệp vụ, data.internal để lấy phiên và thông tin thiết bị. Thiếu session thì mini app có luồng định danh sẽ dừng ngay sau khi render.

Mở Mini App từ deep link​

await VdsMiniApp.openMiniAppFromDeepLink(content, initRequest, parameter, themeConfig);

Gửi event xuống Mini App​

await VdsMiniApp.sendEventToMiniApp(miniAppKey, JSON.stringify(payload), message);

Đóng Mini App​

const closed = await VdsMiniApp.exitMiniApp(miniAppKey);   // true nếu tìm thấy và đã đóng

Overlay component RN đè lên Mini App​

// Đăng ký component trước, ở index.js
AppRegistry.registerComponent('MiniAppOverlayDemo', () => OverlayDemo);

// Rồi mở từ bất cứ đâu
await VdsMiniApp.presentRNOverlayScreen({
  moduleName: 'MiniAppOverlayDemo',
  props: {orderId: '123'},
});

await VdsMiniApp.dismissRNOverlayScreen();

Chỉ một overlay tồn tại tại một thời điểm; gọi lại presentRNOverlayScreen sẽ thay thế overlay đang hiện.

Xử lý sự kiện vòng đời​

Vòng đời mini app đi qua observeLifecycle của host bridge (xem Configuration). Chỉ Android bắn event này — wrapper iOS có implement nhưng native SDK không gọi tới.

Giá trịKhi nào được gọi
InitializationSDK dựng xong WebView, trang mini app bắt đầu nạp
RunningInForegroundMini app hiển thị và nhận tương tác
RunningInBackgroundMini app bị che bởi màn khác hoặc app vào nền
ErrorMini app dừng vì lỗi
UnloadingMini app đóng, WebView sắp bị huỷ

Trên Android mini app chạy ở Activity riêng nên host RN bị đưa xuống nền và timer JS dừng theo — việc cần chạy lúc mini app lên foreground phải móc vào event này. Trên iOS mini app là modal trong cùng process nên timer vẫn chạy, và vì không có event, phải dùng setTimeout.

Bảng API​

APITrả vềGhi chú
initMiniApp(config)Promise<void>
initAndSetupBridge(config, bridge)Promise<void>gộp hai lệnh dưới
setHostAppBridge(bridge)voididempotent
openMiniApp(key, initRequest, parameter?, theme?)Promise<void>
openMiniAppFromDeepLink(content, …)Promise<void>
sendEventToMiniApp(key, data, message?)Promise<void>
exitMiniApp(key)Promise<boolean>
presentRNOverlayScreen({moduleName, props})Promise<boolean>RN-only
dismissRNOverlayScreen()Promise<boolean>RN-only
replyUserData(callbackId, data)Promise<void>trả lời getUserData
setLanguage(language)Promise<string>nhận enum MiniAppLanguage
getLanguage()Promise<string>trả vi | en | sw

Ví dụ hoàn chỉnh​

// index.js — đăng ký overlay trước khi app chạy
AppRegistry.registerComponent('MiniAppOverlayDemo', () => OverlayDemo);
import VdsMiniApp, {BuildVariant, MiniAppLanguage} from '@vdo/vds-rn-sdk';

// 1. Gắn bridge rồi init. setHostAppBridge idempotent — gọi lần hai bị bỏ qua,
//    nên không đổi bridge giữa chừng được.
await VdsMiniApp.initAndSetupBridge(
  {
    apiKey: '<X-API-KEY>',
    partnerKey: '<partnerKey>',
    secretId: '<secretId>',
    variant: BuildVariant.Staging,
    language: MiniAppLanguage.Vietnamese,
  },
  {
    getUserData: (miniAppKey, dataName, callbackId) => {
      VdsMiniApp.replyUserData(callbackId, {msisdn: '84xxxxxxxxx'});
    },
    observeLifecycle: (miniAppKey, lifecycle) => {
      if (lifecycle === 'RunningInForeground') {
        // Android: móc vào đây. iOS không bắn event này.
      }
    },
    expiredSession: () => {},
    intercept: () => {},
  },
);

// 2. Mở mini app
await VdsMiniApp.openMiniApp(
  '01ktay2kqzkmdfk96efg4ybew2',
  initRequest,                       // xem mục "Tạo initRequest"
  {channel: ['APP'], debug: ['true']},
  {headerTitle: 'Mini App', headerColor: '#FFFFFF'},
);

Xử lý lỗi​

Một số lỗi hay gặp khi tích hợp:

Hiện tượngNguyên nhân
Unable to resolve module 'vds-rn-sdk'Câu import còn dùng tên cũ. Từ 2.2.1 package là @vdo/vds-rn-sdk
Mở mini app báo lỗi dữ liệu đầu vàominiAppKey không tồn tại, hoặc không thuộc partner này trên môi trường đang chọn
Mở mini app báo sai partnerpartnerKey sai hoặc không khớp môi trường
Mini app báo lỗi khi lấy thông tin người dùngreplyUserData trả msisdn rỗng
this permission is not yet registered on App CenterQuyền chưa được cấp cho mini app ở App Center
Mini app bấm nút eKYC không phản hồi, không logThiếu @vdo/vds-rn-sdk-ekyc
Mini app báo thiết bị không hỗ trợ quét chip CCCDThiếu entitlement com.apple.developer.nfc.readersession.formats
pod install báo thiếu credential JFrogChưa export JFROG_USERNAME/JFROG_PASSWORD, cũng chưa có ~/.netrc

Lỗi build và runtime khác xem Troubleshooting.
