React Native Configuration

import VdsMiniApp, {
  BuildVariant,
  Logger,
  MiniAppLanguage,
  MiniAppLeftButton,
  MiniAppToolbarMode,
  MiniAppStatusBarMode,
  MiniAppStatusBarForeground,
  MiniAppActionButtonThemeType,
} from '@vdo/vds-rn-sdk';

Khởi tạo VdsMiniApp​

await VdsMiniApp.initAndSetupBridge(
  {
    apiKey: '<X-API-KEY>',                  // trường duy nhất bắt buộc
    partnerKey: '<partnerKey>',
    secretId: '<secretId>',
    variant: BuildVariant.Staging,          // Staging | Uat | Product, mặc định Staging
    language: MiniAppLanguage.Vietnamese,   // mặc định Vietnamese
  },
  hostAppBridge,                        // xem phần dưới
);

Tham số MiniAppInitConfig​

Tham sốKiểuBắt buộcMô tả
apiKeystringCóCấp khi đăng ký Mini App trên App Center
partnerKeystringKhôngCấp khi đăng ký Mini App trên App Center
secretIdstringKhôngCấp khi đăng ký Mini App trên App Center
variantBuildVariantKhôngStaging | Uat | Product, mặc định Staging
languageMiniAppLanguageKhôngMặc định Vietnamese; giá trị lạ rơi về vi

MiniAppInitConfig chỉ nhận năm trường trên. Thông tin thiết bị (imei, osVersion, appVersion…) thuộc initRequest lúc mở mini app, nhánh data.internal.deviceInfo — xem Usage.

Gọi tách rời cũng được:

VdsMiniApp.setHostAppBridge(hostAppBridge);   // idempotent
await VdsMiniApp.initMiniApp(config);

HostAppBridge​

Mọi callback từ native đi qua một kênh duy nhất, nên khai đủ các nhánh app cần:

const hostAppBridge = {
  // Trả dữ liệu người dùng theo yêu cầu của mini app.
  // BẮT BUỘC gọi replyUserData, nếu không mini app treo.
  getUserData: (miniAppKey, dataName, callbackId) => {
    VdsMiniApp.replyUserData(callbackId, {
      msisdn: '84xxxxxxxxx',          // rỗng -> mini app nhận lỗi SDK002
      accountId: '...',
      displayName: '...',
    });
  },

  expiredSession: (miniAppKey, data) => { /* điều hướng về login */ },

  paymentRequest: (miniAppKey, data) => { /* data là object */ },
  paymentStart:   (miniAppKey, request) => { /* request là string */ },
  paymentEnd:     (miniAppKey, request) => {},

  // Vòng đời mini app: Initialization | RunningInForeground |
  // RunningInBackground | Error | Unloading
  observeLifecycle: (miniAppKey, type) => {},

  onBackToHome: (miniAppKey) => {},

  // Host tự dựng màn điều khoản. Chỉ cần KHAI callback này là SDK nhường luồng;
  // giá trị trả về bị bỏ qua. Không khai thì SDK hiện màn mặc định.
  showTermsAndConditions: (miniAppKey, url) => {},

  // Event không nằm trong bảng định tuyến của SDK rơi về đây.
  intercept: (miniAppKey, request) => {},
};

Các handler của HostAppBridge​

HandlerChữ ký (tham số sau miniAppKey)Nền tảngGhi chú
getUserData(dataName: string[], callbackId: string)Cả haiPhải gọi replyUserData, nếu không mini app treo
expiredSession(data: Record<string, any>)Cả haiPhiên hết hạn
paymentRequest(data: Record<string, any>)Cả haiMở luồng thanh toán của host
paymentStart(request: string)Cả hai
paymentEnd(request: string)Cả hai
observeLifecycle(lifecycle: string)AndroidiOS không bắn event này
intercept(request: string)Cả haiEvent ngoài bảng định tuyến của SDK
onBackToHome()Cả hai
showTermsAndConditions(url: string)AndroidKhai là SDK nhường luồng; return bị bỏ qua
startEKYC(request, trackingInput?, accessToken?)AndroidChỉ bắn khi app không có gói eKYC
provideIdfv() => stringAndroidChưa dùng được ở bản này

Ba handler đánh dấu chưa dùng được vẫn nằm trong kiểu dữ liệu, nhưng SDK không gọi tới ở bản này — khai chúng ở JS cũng không có tác dụng.

Ngôn ngữ​

await VdsMiniApp.setLanguage(MiniAppLanguage.English);
const current = await VdsMiniApp.getLanguage();   // 'vi' | 'en' | 'sw'

Đặt trước khi mở mini app để nó nhận đúng ngôn ngữ ngay lần đầu.

Cấu hình Theme (MiniAppThemeConfig)​

openMiniApp nhận themeConfig tuỳ chọn:

await VdsMiniApp.openMiniApp(miniAppKey, initRequest, parameter, {
  leftButton: MiniAppLeftButton.Back,                       // None | Back
  toolbarMode: MiniAppToolbarMode.Normal,                   // Normal | Hidden | Transparent
  statusBarMode: MiniAppStatusBarMode.Display,              // Display | Hidden | Transparent
  statusBarForeground: MiniAppStatusBarForeground.Dark,     // Light | Dark
  actionButtonThemeType: MiniAppActionButtonThemeType.Light, // Light | Dark
  headerTitle: 'Tiêu đề',
  headerColor: '#FFFFFF',
  textColor: '#000000',
  hideIOSSafeAreaBottom: false,
  hideAndroidBottomNavigationBar: false,
});

eKYC​

Gói @vdo/vds-rn-sdk-ekyc xử lý luồng eKYC trong native và trả kết quả thẳng về WebView, không có API JavaScript nào phải gọi. Gói phát hành lần đầu ở 2.2.2-rc01 — xem release note và cấu hình native ở Installation.

Có gói eKYC thì startEKYC trên HostAppBridge không còn được gọi. Ở bản này, người dùng huỷ giữa luồng eKYC thì mini app không nhận được kết quả và treo ở bước đó.
