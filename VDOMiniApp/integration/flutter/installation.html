Bước 1: Export tài khoản JFrog​

export JFROG_USERNAME="<YOUR_USERNAME>"
export JFROG_PASSWORD="<YOUR_PASSWORD>"

⚠️ Liên hệ team phát triển SDK để được cấp tài khoản. Thêm hai dòng trên vào ~/.zshrc hoặc ~/.bashrc để không phải khai lại mỗi phiên terminal.

Bước 2: Cấu hình quyền truy cập JFrog​

Quá trình tích hợp dùng hai loại artifact:

  • dart pub tải mini_app_plugin và mini_app_plugin_ekyc từ repository vdo-pub-packages.
  • CocoaPods và Gradle tải binary native từ các repository nội bộ khác trên cùng JFrog.

Liên hệ team phát triển SDK để được cấp username và token/password JFrog.

2.1. Tạo token truy cập JFrog từ dart pub​

Gọi API token của Artifactory, xác thực bằng chính username/password của bạn:

curl -u "<USERNAME>:<PASSWORD>" \
  -X POST "https://mobile-data.viettelmoney.vn/artifactory/api/security/token" \
  -d "username=<USERNAME>" \
  -d "scope=member-of-groups:*" \
  -d "expires_in=31536000"

Kết quả trả về dạng JSON:

{
  "access_token": "eyJ2ZXIiOiIyIiwidHlwIjoiSldUIiwi...",
  "expires_in": 31536000,
  "scope": "member-of-groups:*",
  "token_type": "Bearer"
}

Lấy giá trị access_token.

expires_in=31536000 là một năm. Đặt 0 để không có thời hạn expired.

2.2. Nhập token cho dart pub​

dart pub token add https://mobile-data.viettelmoney.vn/artifactory/vdo-pub-packages

Lệnh hỏi token qua stdin — dán access_token ở bước 2.1 vào. :::

Bước 3: Khai báo dependency​

Thêm vào pubspec.yaml của app:

dependencies:
  mini_app_plugin:
    hosted: https://mobile-data.viettelmoney.vn/artifactory/vdo-pub-packages
    version: <version>

Mini App có eKYC​

App cần eKYC phải khai cả hai package:

dependencies:
  mini_app_plugin:
    hosted: https://mobile-data.viettelmoney.vn/artifactory/vdo-pub-packages
    version: <version>
  mini_app_plugin_ekyc:
    hosted: https://mobile-data.viettelmoney.vn/artifactory/vdo-pub-packages
    version: <same-version>

rồi chạy:

flutter pub get

Bước 4: Cấu hình iOS​

4.1. Khai báo pod trong Podfile​

Các SDK native là private podspec nằm trong thư mục plugin, không có trên CocoaPods CDN, nên host app phải trỏ đường dẫn tới từng podspec.

Mở ios/Podfile, thêm hai hàm helper ngay trước target 'Runner':

def plugin_private_pods_dir(plugin_name)
  File.expand_path(
    ".symlinks/plugins/#{plugin_name}/ios/PrivatePods",
    __dir__
  )
end

def private_pod_path(plugin_name, name)
  path = File.join(plugin_private_pods_dir(plugin_name), name)

  unless File.directory?(path)
    raise <<~MSG
      [MiniAppPlugin] Cannot find private pod:
        #{path}

      Run `flutter pub get` and check the plugin name.
    MSG
  end

  path
end

Mini App tiêu chuẩn​

target 'Runner' do
  use_frameworks!
  use_modular_headers!

  flutter_install_all_ios_pods File.dirname(File.realpath(__FILE__))

  pod 'VDOUtils',   :podspec => private_pod_path('mini_app_plugin', 'VDOUtils')
  pod 'VDONetwork', :podspec => private_pod_path('mini_app_plugin', 'VDONetwork')
  pod 'VDOMiniApp', :podspec => private_pod_path('mini_app_plugin', 'VDOMiniApp')
end

post_install do |installer|
  installer.pods_project.targets.each do |target|
    flutter_additional_ios_build_settings(target)
  end
end

Mini App có eKYC​

⬆️ Nâng cấp lên 2.2.2

Từ bản này, các framework native chuyển từ nhúng sẵn trong package sang private pod. Nếu bạn nâng từ 2.2.x trở về trước, thêm vào Podfile:

pod 'OpenCV', '3.4.5'

Sau khi đổi version SDK, chạy:

pod update VDOMiniApp VDONetwork VDOUtils
target 'Runner' do
  use_frameworks!
  use_modular_headers!

  flutter_install_all_ios_pods File.dirname(File.realpath(__FILE__))

  # mini_app_plugin
  pod 'VDOUtils',   :podspec => private_pod_path('mini_app_plugin', 'VDOUtils')
  pod 'VDONetwork', :podspec => private_pod_path('mini_app_plugin', 'VDONetwork')
  pod 'VDOMiniApp', :podspec => private_pod_path('mini_app_plugin', 'VDOMiniApp')

  # mini_app_plugin_ekyc
  pod 'VDOEkycService', :podspec => private_pod_path(
    'mini_app_plugin_ekyc', 'VDOEkycService'
  )
  pod 'VDOMiniAppEkycConnector', :podspec => private_pod_path(
    'mini_app_plugin_ekyc', 'VDOMiniAppEkycConnector'
  )
  pod 'NFC',  :podspec => private_pod_path('mini_app_plugin_ekyc', 'NFC')
  pod 'eKYC', :podspec => private_pod_path('mini_app_plugin_ekyc', 'eKYC')

  # Phụ thuộc công khai của eKYC, lấy từ CocoaPods trunk chứ không phải private pod.
  pod 'OpenCV', '3.4.5'
end

post_install do |installer|
  installer.pods_project.targets.each do |target|
    flutter_additional_ios_build_settings(target)

    target.build_configurations.each do |config|
      # eKYC/NFC hiện chỉ có simulator slice x86_64.
      config.build_settings['EXCLUDED_ARCHS[sdk=iphonesimulator*]'] = 'arm64'
    end
  end
end

⚠️ EXCLUDED_ARCHS[sdk=iphonesimulator*] = 'arm64' là bắt buộc với dòng eKYC, và phải áp ở mọi target cùng mọi build configuration. eKYC.xcframework và NFC.xcframework chỉ có slice ios-arm64 và ios-x86_64-simulator, không có arm64-simulator.

4.2. Permissions: bản có eKYC​

Chỉ app dùng mini_app_plugin_ekyc cần thêm vào ios/Runner/Info.plist:

<key>NSCameraUsageDescription</key>
<string>Ứng dụng cần quyền truy cập camera để chụp giấy tờ và xác thực khuôn mặt</string>

<key>NSPhotoLibraryUsageDescription</key>
<string>Ứng dụng cần quyền truy cập thư viện ảnh để chọn ảnh giấy tờ</string>

<key>NSPhotoLibraryAddUsageDescription</key>
<string>Ứng dụng cần quyền lưu ảnh vào thư viện</string>

<key>NSMicrophoneUsageDescription</key>
<string>Ứng dụng cần quyền truy cập microphone để quay video xác thực</string>

<key>NFCReaderUsageDescription</key>
<string>Ứng dụng cần quyền sử dụng NFC để đọc chip trên giấy tờ tuỳ thân</string>

4.3. NFC capability​

Trong Xcode, chọn Runner → Signing & Capabilities → + Capability → Near Field Communication Tag Reading. Xác nhận Runner.entitlements có:

<key>com.apple.developer.nfc.readersession.formats</key>
<array>
  <string>NDEF</string>
  <string>TAG</string>
</array>

4.4. HTTP trên môi trường staging​

Môi trường staging hiện sử dụng endpoint HTTP. Chỉ với build staging, host app cần cấu hình App Transport Security trong Info.plist. Không bật NSAllowsArbitraryLoads cho bản UAT/production nếu các endpoint đều dùng HTTPS:

<key>NSAppTransportSecurity</key>
<dict>
  <key>NSAllowsArbitraryLoads</key>
  <true/>
</dict>

Bước 5: Cấu hình Android​

5.1. Build config​

Ví dụ Groovy trong android/app/build.gradle:

android {
    compileSdk 36

    defaultConfig {
        minSdk 24
        targetSdk 34
    }

    compileOptions {
        sourceCompatibility JavaVersion.VERSION_1_8
        targetCompatibility JavaVersion.VERSION_1_8
    }

    kotlinOptions {
        jvmTarget = '1.8'
    }
}

5.2. Repository native​

Đọc credential đã đặt trong android/local.properties và thêm JFrog Maven repository vào android/build.gradle:

def localProperties = new Properties()
def localFile = rootProject.file("local.properties")
if (localFile.exists()) {
    localProperties.load(localFile.newDataInputStream())
}

def artifactoryUsername = localProperties.getProperty("maven.username") ?:
    System.getenv("MAVEN_USERNAME") ?: ""
def artifactoryPassword = localProperties.getProperty("maven.password") ?:
    System.getenv("MAVEN_PASSWORD") ?: ""

allprojects {
    repositories {
        google()
        mavenCentral()
        maven { url 'https://jitpack.io' }
        maven {
            url = uri(
                "https://mobile-data.viettelmoney.vn/" +
                "artifactory/gradle-viettelmoney"
            )
            credentials {
                username = artifactoryUsername
                password = artifactoryPassword
            }
        }
    }
}

Nếu project dùng dependencyResolutionManagement trong settings.gradle, đặt cùng repository ở đó thay vì allprojects.repositories.

5.3. ProGuard / R8​

Bản release bật R8 mặc định, nên android/app/proguard-rules.pro cần:

-dontwarn kotlinx.android.parcel.Parcelize
-dontwarn kotlinx.parcelize.Parcelize

Thiếu hai dòng này thì flutter build apk --release dừng với ERROR: R8: Missing class kotlinx.parcelize.Parcelize. Từ AGP 8, một class thiếu là lỗi chứ không còn là cảnh báo. App nào đã kéo kotlin-parcelize-runtime qua một dependency gián tiếp thì không gặp lỗi này.

Data Binding — bắt buộc với dòng eKYC​

App dùng mini_app_plugin_ekyc phải bật data binding ở module app:

android {
    buildFeatures { dataBinding true }
}

5.4. Permissions​

Trong android/app/src/main/AndroidManifest.xml:

<uses-permission android:name="android.permission.INTERNET" />
<uses-permission android:name="android.permission.ACCESS_NETWORK_STATE" />
<uses-permission android:name="android.permission.FOREGROUND_SERVICE" />
<uses-permission android:name="android.permission.READ_MEDIA_IMAGES" />
<uses-permission
    android:name="android.permission.READ_EXTERNAL_STORAGE"
    android:maxSdkVersion="32" />

App có eKYC cần thêm:

<uses-permission android:name="android.permission.CAMERA" />
<uses-permission android:name="android.permission.NFC" />

<uses-feature android:name="android.hardware.camera" android:required="true" />
<uses-feature android:name="android.hardware.nfc" android:required="false" />

Giữ NFC ở required="false" nếu app vẫn phải cài được trên thiết bị không có NFC và kiểm tra khả năng đọc chip tại runtime.

Nếu dùng môi trường staging qua HTTP, đặt android:usesCleartextTraffic="true" trong thẻ <application> của manifest dành riêng cho staging/debug. Không bật cho bản UAT/production nếu không cần.

Bước 6: Verify​

Code Dart chỉ import package nền:

import 'package:mini_app_plugin/mini_app_plugin.dart';

Build hai nền tảng:

flutter pub get
cd ios && pod install && cd ..
flutter build ios --debug --no-codesign
flutter build apk --debug
