Migration Guide: 2.2.0 → 2.3.0

Hướng dẫn nâng cấp VDOMiniApp Android từ 2.2.0 lên 2.3.0 (áp dụng từ 2.3.0-rc1).

Nếu đang dùng 2.2.4-rc1 / 2.2.4-rc2, các bước 3 → 6 đã được thực hiện khi nâng lên 2.2.4. Chỉ cần làm các bước 1, 2, 7, 8, 9, 10.

Nếu đang dùng 2.3.0-rc1, chỉ cần làm bước 1 và bước 10.

1. Cập nhật dependency và compileSdk​

implementation("vn.viettelpay:miniappsdk:2.3.0-rc2")
android {
    compileSdk = 36
}

minSdk (24) và targetSdk (35) không đổi.

2. Override HostAppBridge.onAddToMyServicesTapped (bắt buộc)​

HostAppBridge có thêm method suspend không có thân mặc định. Class implement HostAppBridge sẽ không biên dịch được nếu không override method này.

Host không hỗ trợ "My Services":

override suspend fun onAddToMyServicesTapped(
    miniAppKey: String,
    isCurrentlyAdded: Boolean,
    resultHandler: () -> Unit
) {}

Host có hỗ trợ "My Services": override thêm isSupportAddToMyServices() và isAddedToMyServices(miniAppKey), rồi gọi resultHandler() sau khi cập nhật xong để SDK tải lại menu:

override fun isSupportAddToMyServices(): Boolean = true

override fun isAddedToMyServices(miniAppKey: String): Boolean =
    myServicesRepository.contains(miniAppKey)

override suspend fun onAddToMyServicesTapped(
    miniAppKey: String,
    isCurrentlyAdded: Boolean,
    resultHandler: () -> Unit
) {
    if (isCurrentlyAdded) myServicesRepository.remove(miniAppKey)
    else myServicesRepository.add(miniAppKey)
    resultHandler()
}

3. Đổi kiểu trả về của HostAppBridge.intercept​

intercept đổi kiểu trả về từ Unit sang Boolean.

Trước:

override fun intercept(miniAppKey: String, message: String) {
    // ...
}

Sau:

override fun intercept(miniAppKey: String, message: String): Boolean {
    // ...
    return false
}
  • Trả false = host không xử lý event này, SDK trả SDK100 ("Unknown event") cho mini app.
  • Trả true = host nhận xử lý event, và bắt buộc trả lời đúng một lần qua MiniAppSdk.getInstance().sendToMiniApp(miniAppKey, data), với data là phong bì JSON mang requestId trùng với yêu cầu. Nếu không, trang mini app sẽ chờ tới khi hết thời gian.

4. Cập nhật MiniAppComponents.createMiniAppWebView (nếu tự cài đặt)​

Chỉ áp dụng khi tự cài đặt MiniAppComponents hoặc kế thừa MiniAppWebView. Method và constructor thêm tham số themeController: ThemeController:

override fun createMiniAppWebView(
    context: Context,
    miniAppBridge: MiniAppBridge,
    miniAppWebChromeClient: MiniAppWebChromeClient,
    miniAppWebViewClient: MiniAppWebViewClient,
    themeController: ThemeController
): MiniAppWebView = MiniAppWebView(
    // ...
    themeController = themeController
)

5. Gỡ tham chiếu tới năng lực gọi điện​

Các ký hiệu sau đã bị gỡ, phải xóa mọi tham chiếu:

  • MiniAppEvent.OPEN_PHONE_CALL
  • MiniAppEvent.REQUEST_PHONE_CALL_PERMISSION
  • MiniAppEvent.CHECK_PHONE_CALL_PERMISSION
  • PermissionCode.PHONE_CALL_PERMISSION

MiniAppActionType.REQUEST_PHONE_CALL_PERMISSION, MiniAppActionType.CHECK_PHONE_CALL_PERMISSION và OpenPhoneRequest vẫn còn nhưng đã @Deprecated và không còn nhánh xử lý. Mini app gọi các event này sẽ nhận SDK100.

6. Xử lý mã lỗi mới (khuyến nghị)​

Nếu host đọc ErrorCode bằng when dạng exhaustive, cần thêm nhánh cho: SDK100, SDK800, SDK801, SDK802, SDK830, SDK840, SDK850, SDK851, SDK852.

7. Thêm nhánh MiniAppMenuActionKey.REMOVE_FAVOURITE​

Nếu host có when dạng exhaustive trên MiniAppMenuActionKey, thêm nhánh cho REMOVE_FAVOURITE.

8. Cập nhật code đọc MiniAppThemeConfigDto.hideAndroidBottomNavigationBar (nếu có)​

Field này đổi kiểu từ Boolean? sang Any?. Nếu host đọc trực tiếp field này, hãy dùng toMiniAppThemeConfig().hideAndroidBottomNavigationBar để nhận Boolean? đã chuẩn hoá.

9. Cập nhật code gọi GetListPermissionConfigUseCase (nếu có)​

invoke(miniApp, context) giờ trả về Flow<List<PermissionConfigUiModel>>:

val permissions = getListPermissionConfigUseCase(miniApp, context).first()

10. Thêm nhánh BuildVariant.StagingPrivate (từ 2.3.0-rc2)​

BuildVariant có thêm entry StagingPrivate (https://staging.viettelmoney.vn/). Nếu host có when dạng exhaustive trên BuildVariant, thêm nhánh cho StagingPrivate:

when (variant) {
    BuildVariant.Staging -> { /* ... */ }
    BuildVariant.StagingPrivate -> { /* ... */ }
    BuildVariant.Uat -> { /* ... */ }
    BuildVariant.Product -> { /* ... */ }
}

Thay đổi hành vi cần kiểm tra​

  • BuildVariant.Staging trỏ tới https://staging1.viettelmoney.vn/ thay vì địa chỉ IP HTTP cũ.
  • Trạng thái quyền kiểu USER_DATA được đồng bộ với App Center qua endpoint mới /app-center/api/v1/public/open-api/permissions/customers/mini-apps/status và .../confirm. Môi trường backend phải triển khai các endpoint này trước.
  • Cache quyền dùng khóa mini app dạng chữ thường. Mini app có khóa chứa chữ hoa có thể phải cấp lại quyền một lần sau khi nâng cấp.
  • Mục menu SHARE và ADD_TO_DEVICE dùng trường deepLink của mini app trên App Center. Host app phải xử lý được deeplink này.
