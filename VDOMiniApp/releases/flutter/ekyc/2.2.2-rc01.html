Release Notes - mini_app_plugin_ekyc 2.2.2-rc01

Version: 2.2.2-rc01 Release date: 2026-09-22 Build number: 20260922115817

Package mới, tách khỏi mini_app_plugin. Cần luồng định danh thì khai cả hai package, cùng version.

Changelog​

Added​

  • eKYC tách thành package Flutter riêng, phát hành qua Pub repository vdo-pub-packages cùng version với mini_app_plugin.

Changed​

  • Framework native chuyển từ nhúng sẵn trong package sang private pod.

Package này làm gì​

Không có API Dart. Toàn bộ phần việc nằm ở tầng native: mang binary eKYC và gắn chúng vào điểm mở rộng của mini_app_plugin. Mã nguồn app vẫn import và gọi API từ mini_app_plugin.

Bỏ package ra thì app vẫn build xanh và mini app thường vẫn chạy — chỉ riêng luồng eKYC không khởi tạo được.

Yêu cầu thêm so với dòng chuẩn​

Hạng mụcGiá trị
iOS deployment target13.0
pod 'OpenCV', '3.4.5'bắt buộc khai trong Podfile
EXCLUDED_ARCHS[sdk=iphonesimulator*] = 'arm64'bắt buộc, ở mọi target và mọi build configuration

eKYC.xcframework và NFC.xcframework chỉ có slice ios-arm64 và ios-x86_64-simulator, không có arm64-simulator. Thiếu phép loại trừ thì lỗi hiện ra muộn, dưới dạng Unable to find module dependency.

OpenCV phải khai ở Podfile chứ không thể để podspec tự kéo: opencv2.framework là static, và CocoaPods chặn cạnh pod→pod tới static binary với transitive dependencies that include statically linked binaries.

Data Binding — bắt buộc​

Khai ở module app:

android {
    buildFeatures { dataBinding true }
}

Bật dataBinding là thứ làm lớp BR được sinh ra thật. Tắt cảnh báo của R8 không thay thế được việc đó — lớp vẫn thiếu, và lỗi chỉ dời từ lúc build sang lúc chạy.

Các dòng ProGuard của dòng chuẩn vẫn áp dụng như thường.
