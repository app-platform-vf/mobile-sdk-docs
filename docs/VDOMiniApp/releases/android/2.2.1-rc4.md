# Release Notes — VDOMiniApp Android 2.2.1-rc4

**Version:** 2.2.1-rc4
**Platform:** Android
**Build:** 20260723173801 (2026-07-23 17:38:01)

## Changelog

### Added

- `FileType.ImageJpeg` (`"image/jpeg"`), `FileType.ImageJpg` (`"image/jpg"`), `FileType.ImagePng` (`"image/png"`) — enum entry mới tại `vn.viettelpay.miniappsdk.common.core.FileType`. File chooser giờ map các mime image cụ thể này về `PermissionCode.PHOTOS_PERMISSION`.
- `ThemeController.reloadTheme()` — public method mới, phát lại theme hiện tại tới các listener (`notifyThemeChanged()`).
- `MenuActionListener.onMenuDismissed()` — default method mới trên interface, được gọi sau khi menu bottom sheet đóng. Cho phép host cập nhật lại toolbar theme khi mini app trở lại foreground.

### Changed

- `MiniAppActivity` — bật edge-to-edge rendering (`WindowCompat.setDecorFitsSystemWindows(window, false)`) và cấu hình display cutout mode (`LAYOUT_IN_DISPLAY_CUTOUT_MODE_ALWAYS` trên API ≥ 30, `LAYOUT_IN_DISPLAY_CUTOUT_MODE_SHORT_EDGES` trên API ≥ 28), giúp mini app vẽ tràn qua vùng notch/cutout.
- `MiniAppWebView` — keyboard listener giờ được bật cho mọi host app (trước đây chỉ bật cho `com.bplus.vtpay`). Constructor thêm tham số `themeController: ThemeController`; chiều cao WebView khi bàn phím mở được tính lại dựa trên `toolbarMode` và `statusBarMode` hiện tại thay vì chỉ theo status bar inset.
- `MiniAppComponents.createMiniAppWebView(...)` — abstract method thêm tham số `themeController: ThemeController`.
- Theme update qua JS bridge (`MiniAppEvent.UPDATE_MINI_APP_THEME`) — status bar và navigation bar không còn được set thủ công trong `MiniAppBridgeImpl`; toàn bộ được ủy quyền cho `ThemeController.setTheme(param)`, thống nhất luồng cập nhật theme.
- Overlay child mini-app — permission cache dùng `parentMiniAppKey` khi manifest `isOverlayWebView`, để child overlay chia sẻ quyền với parent.
- SDK permission bottom sheet — thêm callback `onClose` reload theme sau khi bottom sheet đóng; `SDKPermissionHandler` giờ nhận `MiniAppDisplay` thay cho `MiniAppNavigator` (điều hướng policy/external url đi qua `MiniAppDisplay as? MiniAppNavigator`).
- Insets handling — `MiniAppFragment` và `VdoPermissionConfigFragment` dùng `setPadding` theo system bars; padding bottom được thêm khi `hideAndroidBottomNavigationBar != true`.
- Toolbar title (`toolbarTitle`) giờ luôn hiển thị ở các chế độ `ToolbarMode.NORMAL` và `ToolbarMode.TRANSPARENT`.

### Fixed

- Tránh crash khi pop back stack sau khi state đã được lưu — thêm guard `!fm.isStateSaved` và `try/catch` trong `MiniAppDisplayDefault`.
- Lỗi parse param khi lấy contact do permission giờ trả về `failedToParseParamMessage` với message gốc thay vì message contact-permission-specific.
